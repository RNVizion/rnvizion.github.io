Selected Projects
  • AIII: Artificial Intelligence Identification Initiative · rnvizion.dev/aiii — Apache-2.0 reference implementation for AI agent identity: an L1–L3 identity-and-authorization layer for MCP servers, built on one principle: resolve or refuse, never guess. Holder-of-key verification (RFC 7800/7638), declarative per-tool authorization, 46 tests with property-based eval gates, and cross-platform CI with lint and SAST. Supply chain: DCO enforced in CI, Sigstore-signed release manifests, a CycloneDX SBOM per release, and an OpenSSF Best Practices Baseline submission at 20 of 21 controls, with the one exception documented rather than hidden. Source at github.com/RNVizion/rnv-mcp-identity, with a live demo on Hugging Face Spaces.
  • rnv-color-mcp · github.com/RNVizion/rnv-color-mcp — Color-computation server on the Model Context Protocol (FastMCP), published to the official MCP registry and listed in awesome-mcp-servers. Nine deterministic tools spanning color conversion, harmony generation, mixing, palette management, WCAG contrast (AA/AAA), and perceptual difference (CIEDE2000). Also an OAuth 2.1 resource server: RFC 9728 protected-resource metadata and enforced per-tool scopes over a read and write split, 18 tests green in CI. One shared engine, callable by any LLM client: the model decides intent, the tool owns the exact value. MIT licensed, live on Hugging Face Spaces.
  • Ask the Corpus · huggingface.co/spaces/RNVizion/ask-the-corpus — Live retrieval-augmented (RAG) assistant answering questions over my published writing: sentence-transformers embeddings and ChromaDB vector search, grounded through Claude with source citations, plus rate limiting and per-call cost guardrails. Quality is CI-gated: a 60-case evaluation suite covering retrieval, out-of-corpus refusal, and false refusal, including deliberate traps, runs on every change to the app, the ingestion path, or the corpus, and fails the build if any of three thresholds regresses: retrieval accuracy at or above 85%, out-of-corpus refusal at or above 90%, and false-refusal rate at or below 10%. Gradio UI, deployed live on Hugging Face Spaces.
  • RNV Publishing Agent · github.com/RNVizion/rnv-publishing-agent — FastMCP server exposing four tools, orchestrated by a Claude agent loop to automate an end-to-end content-publishing workflow; built and tested in GitHub Codespaces.
